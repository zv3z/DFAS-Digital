نظام التحليل الجنائي لـ الجرائم الرقمية

DFAS هو منصة تحليل جنائي رقمي متكاملة تعمل بالكامل بدون إنترنت (Offline-First)، مُصمَّمة لكشف وتحليل الجرائم الإلكترونية في البيئة العربية. تجمع 10 محركات تحليل سيبراني في واجهة عربية كاملة — من تحليل التصيد وكشف IOC وجنائيات الصور إلى التحليل الإحصائي للإخفاء الرقمي وتعيين الهجمات على إطار MITRE ATT&CK — مع قاعدة بيانات IndexedDB محلية وتقارير جنائية موثقة وفق المعايير الدولية.

ISO/IEC 27037:2012NIST SP 800-86RFC 3227 ACPO Guidelines v5TLP:AMBERIndexedDBOffline-First
❓
المشكلة والحل

تفتقر البيئة العربية إلى أدوات تحليل جنائي رقمي باللغة العربية. DFAS يسد هذه الفجوة بـ:

  • تحليل الرسائل والروابط والصور والبريد عربياً
  • كشف 47+ مؤشر للاحتيال والتصيد باللغة العربية
  • تقارير جنائية موثقة وفق ISO/IEC 27037
  • عمل كامل offline لحماية الأدلة الحساسة
  • قاعدة بيانات IndexedDB لحفظ سجل القضايا

المحركات التقنية — تفصيل كامل
MOD-01 — Phishing Detection Engine
  • 9 فئات: استعجال، انتحال، طلب بيانات، إغراء مالي، تهديد...
  • 47 مؤشر لغوي وسلوكي للنصوص العربية والمختلطة
  • كشف الروابط المضمّنة والخلط اللغوي المشبوه
MOD-02 — URL Analysis Engine
  • 13 معيار: TLD، IP مباشر، Typosquatting، Phishing Paths...
  • Shannon Entropy لكشف نطاقات DGA
  • Open Redirect + Percent-Encoding Detection
MOD-03 — Image Forensics Engine
  • EXIF/XMP Metadata Extraction الكاملة
  • Error Level Analysis (ELA) لكشف التزوير
  • Photoshop Signature + Timestamp Conflict Detection
MOD-04 — Email Header Analysis
  • SPF / DKIM / DMARC Authentication Check
  • Routing Chain Visualization
  • From ↔ Return-Path ↔ Reply-To Mismatch Detection
MOD-06 — IOC Detection Engine
  • 18 نمط Regex لكشف: IPs، نطاقات، هاشات، CVEs، Crypto
  • تصنيف تلقائي بـ 8 فئات مع تقييم مستوى الخطورة
  • كشف PowerShell, Macro, Registry, Named Pipes, YARA
MOD-07 — Steganography Detection Engine
  • LSB (Least Significant Bit) Analysis على قنوات RGB
  • Chi-Square Statistical Test لكشف التوزيع غير الطبيعي
  • Pixel Pair Analysis (RS Method) للكشف الدقيق
MOD-08 — Digital Timeline Engine
  • 7 صيغ طوابع زمنية: ISO8601، Syslog، Apache، Windows...
  • كشف الشذوذ: فجوات، انفجارات، توقيت خارج الدوام
  • SVG Timeline Visualization مع ترتيب تسلسلي
MOD-09 — Network Log Analysis Engine
  • 10 مسارات Exploit معروفة + 3 User-Agent ماسحين
  • كشف Brute Force، SQL Injection، Path Traversal، Log4Shell
  • إحصاء Top IPs وتوزيع أكواد HTTP وحجم البيانات
MOD-10 — MITRE ATT&CK Framework Mapper
  • قاعدة بيانات 28 تقنية ATT&CK في 13 تكتيك مُدمجة محلياً
  • 18 قاعدة تعيين تلقائي من النص إلى تقنيات ATT&CK
  • Kill Chain Stage Estimation وتصنيف مرحلة الهجوم
  • ATT&CK Matrix SVG Visualization تفاعلية
